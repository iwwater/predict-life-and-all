# 增删卜易 · 精选段落（六爻）

> 《增删卜易》为清代野鹤老人所著，是最实用的六爻占卜经典之一。

## 用神章

用神者，即所占之事也。占父母以父母爻为用神，占兄弟以兄弟爻为用神，占妻妾以妻财爻为用神，占子孙以子孙爻为用神，占官讼以官鬼爻为用神。

用神旺相有气则吉，用神休囚无气则凶。用神持世则事必由己，用神生世则事必相关。

*出处：《增删卜易》「用神章」*

## 世应章

世为我，应为彼。世应相生则彼此相合，世应相克则彼此相背。世克应则我不利于彼，应克世则彼不利于我。

世应之位，以卦宫定之。八纯卦世在六爻，一世卦世在初爻，二世卦世在二爻，三世卦世在三爻，四世卦世在四爻，五世卦世在五爻，游魂卦世在四爻，归魂卦世在三爻。

*出处：《增删卜易》「世应章」*

## 动变章

爻逢发动，乃变化之机。动爻为事之始，变爻为事之终。动爻所临之六亲为事发之因，变爻所临之六亲为事成之果。

动逢月破则无力，动逢旬空则不实。动而化进神则事有进展，化退神则事有退步。

*出处：《增删卜易》「动变章」*
