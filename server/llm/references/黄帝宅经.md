# 黄帝宅经 · 精选段落（八宅风水）

> 《黄帝宅经》是中国现存最早的住宅风水经典，托名黄帝所作，实际成书于南北朝至唐代。

## 卷上

夫宅者，乃是阴阳之枢纽，人伦之轨模。非夫博物明贤，未能悟斯道也。

宅者，人之本。宅以形势为骨体，以泉水为血脉，以土地为皮肉，以草木为毛发，以舍屋为衣服，以门户为冠带。若得如斯，是事俨雅，乃为上吉。

*出处：《黄帝宅经》卷上*

## 论八卦方位

八卦之方位，以坎离震兑为四正，以乾坤艮巽为四维。四正者，子午卯酉之位也。四维者，乾坤艮巽之位也。

凡宅之吉凶，视其门路之所向。门在吉方则吉，门在凶方则凶。门为宅之气口，犹人之口鼻也。

*出处：《黄帝宅经》「论八卦方位」*

## 论阴阳

阴者生化物之母也，阳者生化物之父也。阴阳配合而万物生焉。

宅有阴阳之气，居者当以阳宅养阳德，以阴宅养阴德。凡人居止之室，宜居有德之乡。

*出处：《黄帝宅经》「论阴阳」*
