# 三命通会 · 精选段落（八字命理与格局）

> 《三命通会》为明代万民英编撰，是收录最全面的命理巨著。
> 择取格局相关核心段落。

## 卷四 · 论正官

正官者，乃阴见阳、阳见阴，阴阳相制而成也。正官为六格之首，喜印绶以卫之，忌伤官以伤之。

正官格宜身旺，官星有气，再得印绶护卫，则为贵格。若身弱官强，再逢伤官，则为破格。

*出处：《三命通会》卷四「论正官」*

## 卷五 · 论七杀

七杀者，阳见阳、阴见阴，同类相克也。七杀性刚，如能制化则为权柄。

杀印相生，文武兼备。食神制杀，英雄独压万人。杀无制则小人之辈。

*出处：《三命通会》卷五「论七杀」*

## 卷六 · 论财

财为养命之源。正财者，日主所克而与日主异阴阳者是也。偏财者，日主所克而与日主同阴阳者是也。

财宜藏，藏则丰厚；不宜露，露则浮荡。财格喜身旺，方能任财。身弱财旺，反为富屋贫人。

*出处：《三命通会》卷六「论正财」*

## 卷七 · 论印绶

印绶者，生我者也。正印为生气之源，偏印为偏生之助。印格以官杀为配合之主。

印多变枭，夺食为灾。印旺身强，何劳印绶；印轻身弱，必须印扶。

*出处：《三命通会》卷七「论印绶」*

## 卷九 · 论大运吉凶

大运之吉凶，以本命为主。大运干支与四柱配合，刑冲克害，乃判吉凶之机。

行运之要，以用神为宗。运助用神则吉，运克用神则凶。大运重地支，流年重天干，此为要诀。

*出处：《三命通会》卷九「论大运」*
