# 梅花易数 · 精选段落

> 《梅花易数》传为宋代邵雍（邵康节）所著，是象数派易学最重要的经典之一。

## 卷一 · 体用总诀

体用者，即一卦之体用也。以体为己身之兆，用为应事之端。体用之间，比和则吉，生克则凶。

体克用则诸事可成，用克体则诸事难遂。体生用则有耗损之忧，用生体则有进益之喜。体用比和则百事顺遂。

*出处：《梅花易数》卷一「体用总诀」*

## 卷一 · 八卦万物属类

乾为天、为君、为父、为金、为玉、为马、为首。
坤为地、为母、为土、为布、为釜、为牛、为腹。
震为雷、为龙、为木、为竹、为足、为长男。
巽为风、为鸡、为木、为绳、为股、为长女。
坎为水、为猪、为月、为耳、为中男。
离为火、为雉、为日、为目、为中女。
艮为山、为狗、为土、为手、为少男。
兑为泽、为羊、为金、为口、为少女。

*出处：《梅花易数》卷一「八卦万物属类」*

## 卷二 · 占卜总论

占卜之道，以象为主，以数为用。观象可以知事之吉凶，察数可以明事之始终。

凡占，先看体用。体为主，用为客。以体用生克决吉凶，以互变二卦看过程。

*出处：《梅花易数》卷二「占卜总论」*
