# 沈氏玄空学 · 精选段落

> 《沈氏玄空学》为清代沈竹礽所著，是玄空飞星风水最重要的系统著作。

## 论三元九运

三元者，上元、中元、下元也。每元三运，每运二十年。上元一运坎、二运坤、三运震；中元四运巽、五运中、六运乾；下元七运兑、八运艮、九运离。

三元九运共一百八十年，周而复始。每运以当运之星为旺气，失运之星为衰气。

*出处：《沈氏玄空学》卷一「论三元九运」*

## 论宅命

宅之有运，犹人之有命。宅运以坐山为主，向首为用。坐山为阴，向首为阳。阴阳配合，乃成宅命。

山主人丁，向主财禄。山管人丁水管财，此言不虚也。

*出处：《沈氏玄空学》卷二「论宅命」*

## 论飞星

飞星之法，以运盘之星入中宫，依洛书轨迹顺飞九宫，得运星盘。再以坐山之星入中宫，依坐山阴阳顺逆飞，得山星盘。再以向首之星入中宫而飞，得向星盘。

三盘叠合，乃成宅盘。山星管人，向星管财，运星管时运。看一宅之吉凶，需三盘同参。

*出处：《沈氏玄空学》卷三「论飞星」*

## 论旺山旺向

旺山旺向者，山星之当令到山，向星之当令到向也。此为宅盘之最吉者，主丁财两旺。

上山下水者，山星之当令到向，向星之当令到山，此为颠倒之局，主丁财两失。

*出处：《沈氏玄空学》卷四「论旺山旺向」*
