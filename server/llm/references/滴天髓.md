# 滴天髓 · 精选段落（八字命理）

> 《滴天髓》传为明代刘基（刘伯温）所注，是八字命理中最精深的经典之一。
> 以下为通神论核心段落摘录。

## 上篇 · 通神论 · 天道

欲识三元万法宗，先观帝载与神功。
坤元合德机缄通，五气偏全定吉凶。

*释义：想了解天、地、人三元的根本法则，先观察天道运行的规律。天地之气相合，五行之气偏全，决定了吉凶祸福。*

## 上篇 · 通神论 · 地道

戴天履地人为贵，顺则吉兮凶则悖。
要与人间开聋聩，顺逆之机须理会。

*释义：人立于天地之间，顺应天地之道则吉，悖逆则凶。要明白命运的顺逆机理。*

## 上篇 · 通神论 · 人道

阳乘阳位阳气昌，最要行程安顿。
阴乘阴位阴气盛，还须道路光亨。

*释义：阳干得阳支则气势昌盛，关键在大运是否安顿。阴干得阴支则阴气旺盛，还须行运光明亨通。*

## 上篇 · 通神论 · 知命

要与人间开聋聩，顺逆之机须理会。
理承气行岂有常，进兮退兮宜抑扬。

*释义：命理进退并非固定不变，需根据行运之势来决定进取还是退守。*

## 上篇 · 通神论 · 配合

配合干支仔细详，定人祸福与灾祥。
官杀混杂须去留，去留舒配要参详。

*释义：干支配合需要仔细分析，决定祸福与吉凶。官杀混杂时要分清去留，取舍配置需要参详。*

## 上篇 · 通神论 · 体用

道有体用，不可以一端论也，要在扶之抑之得其宜。

*释义：命理有体与用两个方面，不能单看一端。关键在于该扶助时扶助，该抑制时抑制，各得其所。*

## 下篇 · 六亲论

夫妻姻缘宿世来，喜神有意傍天财。
子女根枝一世传，喜神看与杀相连。

*释义：夫妻缘分来自前世，看配偶当看财星（男命）或官星（女命）。子女传承一世，看食伤与官杀的关系。*
