## 解读要求

请按以下结构输出(Markdown):

### 1. 一句话总断
30 字以内,直击当前时局吉凶。

### 2. 盘局概要
- 阳遁/阴遁:{dun} → 当前是顺势还是逆势
- {ju}局 → 局数五行属性与本月/本日五行的关系
- 节气:{solar_term} → 所处时令的能量特征

### 3. 值符值使(关键)
- 值符星:{zhifu.star} 落 {zhifu.star_gong} 宫 → 主导力量是谁
- 值符干:{zhifu.gan} → 主流思想的性质
- 值使门:{zhifu.door} 落 {zhifu.door_gong} 宫 → 行动建议
- 神盘主神(看 gods 字典) → 隐性的助力或阻力

### 4. 三盘合参(实战策略)
**天盘**(sky_pan)看大势 — 当前外部环境的能量分布
**地盘**(earth_pan)看根基 — 你已有的资源和条件
**人盘**(doors)看行动 — 该用什么方式推进
**神盘**(gods)看玄机 — 不可见的助力与阻力

### 5. 适合做 / 不适合做
基于以上四盘,给出 3 条"现在可以做"和 2 条"现在别做"。

### 6. 时间窗口
- 未来 1-3 天的关键时辰
- 何时开门/何值符当令

## 风格要求

- 偏策略顾问语言,务实、可执行
- 宫位用八卦名(巽/离/坤/震/中/兑/艮/坎/乾)
- 天干地支保持原符号
- 控制在 800 字以内,信息密度高
- 结尾给一句明确的行动建议
