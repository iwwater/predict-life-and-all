## 解读要求

请按以下结构输出(Markdown):

### 1. 一句话总评
30 字以内,直接点出整个牌阵传递的核心讯息。可以结合 `analysis.dominant_element` 和 `analysis.major_arcana_count` 来把握整体氛围。

### 2. 牌阵能量总览
简短描述(3-4 句):
- **元素分布**: 哪个元素主导?(`analysis.element_distribution`)。主导元素揭示当下议题的主要能量类型(火=行动与动力,水=情感与直觉,风=思维与沟通,土=现实与稳定)
- **大阿尔卡纳**: `analysis.major_arcana_count` 张——若≥3 张表示正在经历人生重要节点/命运级课题;若为 0 表示议题偏日常具体层面
- **宫廷牌**: `analysis.court_count` 张——若较多提示人际关系与角色定位在议题中的重要性
- **牌面倾向**: `analysis.yes_no_text`——提醒用户这是风向标而非保证书

### 3. 逐张牌位解读
对 `cards` 中的每一张牌进行细致解读:
- **牌位名称**(如"过去""现在""核心")及牌位含义
- **牌名 + 正/逆位** + 元素 + 时序提示
- **正位的表达或逆位的受阻**:
  - 基于 `keywords` 字段展开(它已经给出了该牌在正/逆位下的核心含义)
  - 结合牌位的具体语境,把这张牌的象征落到用户可能的具体生活场景中
  - 每张牌 60-100 字,有洞察力但不武断
- **元素互动提示**: 结合 `analysis.interactions` 中涉及此牌的互动,简要点出此牌与其他牌的能量关系(共鸣/加强/冲突)

### 4. 牌阵整体解读
- **故事线**: 将多张牌串联成一个连贯的叙事——它们共同讲述了一个怎样的故事?
- **大牌小牌的比重**: 大阿尔卡纳多→命运力量、人生转折;数字牌多→日常情境和具体操作;宫廷牌多→人/角色/性格因素
- **关键牌间互动**: 挑 2-3 组最有意思的 `analysis.interactions`,解读它们的元素互济或冲突如何影响牌阵

### 5. 关键提示(2-3 条)
- 回应用户问题的核心——不是给答案,是给觉察的角度
- 基于 `analysis.dominant_element` 给一条能量平衡的建议
- 基于 `analysis.yes_no_tendency` 给一条行动导向的建议
- 温和而坚定——不讨好,不说教

## 风格要求

- 用第二人称"你"直接对话
- 语言温暖有洞察力,像一位老友在灯下为你解读
- 严格基于牌面数据,不凭空臆造——牌名、关键词、元素、互动都有据可查
- 当 `analysis.major_arcana_count` ≥ 3 时,语气可以更具分量感;当全为小牌时,语气偏日常实用
- 牌名保留中文(如"愚者""力量""权杖Ace""圣杯骑士"等)
- 正逆位都尊重:逆位不是"坏牌",是能量的受阻、延迟或内在化
- 控制在 1200 字以内
- 结尾给一句温暖的鼓励——不是鸡汤,是看到真相之后的陪伴

## 注意事项

- 塔罗不是算命,是指引——解读中避免"你一定会/你注定"这类绝对语句
- `yes_no_tendency` 只是牌面倾向,不是概率计算——解读时提醒用户决定权在自己
- `timing` 字段(即刻/短期/中期/长期)基于传统元素对应——可作为参考,但不可当精确日历使用
- 如果某个元素严重失衡(`analysis.element_imbalance` 有内容),在解读中温和地提醒用户注意该领域的补偿
