# 第一部分 · 项目总结（到目前为止）

## 走过的路

1. **起点**：X 帖子 8 个开源算命项目，问"能不能融"。实地下载核查后发现帖子多处不实（BaziEval 是假引擎、yuan 是 Skill 包非服务、fortuneteller-api 是别人的付费 SDK），8 个里仅 4 个有 license。结论：不融代码，以有授权的成熟库为引擎、repo 退为参考。
2. **路线决策**：选 **B 路（纯 MIT 可闭源）**——西方占星不用 AGPL 的 Swiss Ephemeris，改 skyfield(MIT)+JPL 公版星历+自算星座/宫位/相位。
3. **深度验证**（抓出 3 个真 bug 并修复）：`ecliptic_latlon` 经纬顺序反、必须用当日黄道 `epoch=t`(岁差)、均时差须用平黄经。验证项：上升点反推地平高度=0.000°、Placidus 半弧自洽 5 纬度<0.01°、均时差 5 已知日<0.1 分钟、历史夏令时(1986–91 中国)自动正确。
4. **12 法引擎**（统一接口 `compute(method,birth)`，全部文献校验）：
   - 东方·命：八字(真太阳时)、紫微 ｜ 东方·卜式：奇门(三元定局对《烟波钓叟歌》7 节气全合)、六爻(64 卦/纳甲/八宫世应全验)、梅花、称骨 ｜ 东方·风水：八宅、玄空(八运子山午向=双8到向等 4 局全合) ｜ 西方：占星、吠陀、塔罗、数字命理。
5. **断法层**：奇门格局(门迫/入墓/空亡/五不遇时)、六爻用神(旬空/月破/旺衰)、梅花体用(修正过一处吉凶方向反的真错)、八字粗判。
6. **解读层**：读法规范 prompt(保守口径/中西合参/禁绝对化) + 护栏(危机转介/医疗法财转介/绝对化软化/免责) + 可插拔 LLM。
7. **深化**：塔罗(78 张全正逆牌义+大牌占星对应+6 牌阵+牌组分析)、吠陀(罗睺计都+九分盘 D9+庙旺落陷+Vimshottari 大运/副周期，Dasha=120 年等全验)。
8. **你已落地**：Mystic Hub（12 法聚合+API+前端+Docker+408 测试）。
9. **已出的规划文档**：前端设计计划书（API 契约+12 法盘面规格+合规）、下阶段计划（化解层+风水平面图+伦理红线）、实现级开发方案（Remedy 模型/平面图几何算法/验收清单）。

## 全程方法论（也是准度的来源）
**不凭记忆写定数 → 凡可验证必先验证 → 不确定的如实标注留校订位 → 抓出错就修并写明原因。** 一路抓修的真错共 5 处：经纬顺序、岁差黄道、均时差、梅花体用方向、Navamsa 浮点边界。

# 第二部分 · 准度提升开发计划（新一期主线）

> 纲领：**准度 > 功能**。本期不加新术数，把"能跑"全部提到"对得起专业对照"。
> 我把一路如实标注过的**每一处简化/待校订**列成清算清单——这就是准度的全部已知缺口。

## A. 已知缺口清算表（逐项：问题 → 修法 → 验证）

### A1 八字（影响最大，优先级最高）
| 缺口 | 现状 | 修法 | 验证 |
|------|------|------|------|
| 五行计数太粗 | 只数干支表面五行，**未计地支藏干** | 按藏干表（子藏癸、丑藏己癸辛…）加权计入（本气1.0/中气0.6/余气0.3 类通行权重，标注流派） | 对命理书标准案例的五行论断 |
| 旺衰只看得令 | 仅月令生扶 | 加**通根**（日主在四支藏干有无根、根之远近）+ 得地得势，输出强弱分级而非二值 | ≥20 个《滴天髓》/教材案例盲测，与书中旺衰结论一致率 ≥90% |
| 无喜用神 | 留给 LLM | 实现扶抑取用（强抑弱扶）+ 调候参照（《穷通宝鉴》月令调候表），两法并陈 | 同上案例集对照 |
| 子时换日未暴露 | 用 lunar-python 默认 | 查明其默认（早/晚子），加 `options.zi_hour` 显式开关 | 23:30 生人两种开关下日柱不同且各自正确 |
| 神煞缺失 | 无 | 补常用神煞（天乙贵人/桃花/驿马/华盖/羊刃…查表） | 对万年历类工具抽查 |

### A2 排盘对照（全法横向）
**建立"专业软件对照集"**：每法选 10–20 个测例（含边界），与公认专业排盘工具人工对照一次，结果存为 golden 文件进 CI。
- 八字/紫微：对照主流专业排盘（含 1986–91 夏令时生人、节气交界±1 小时、闰月）。
- 西方：对照 astro.com（行星度数差 ≤0.1°、宫头 ≤0.5°、上升 ≤0.5°）。
- 吠陀：对照标准 Jyotish 软件（Lahiri 下行星宫位、Dasha 切换年月）。
- 奇门：拆补/置闰两法各对照排盘书例局。
- 玄空：对照《沈氏玄空学》下卦图全 16 局抽 8 局。

### A4 解读准度（不只排盘准，话也要准）
- **盲测协议**：每法 10 例 → LLM 解读 → 对照"该盘文献标准断语要点"，人工评分（命中/遗漏/杜撰三率）。**杜撰率是红线指标**：解读中出现盘面没有的"事实"即记杜撰，目标 <2%。
- **断语知识注入**：把断法层输出（用神旺衰/格局/体用…）从"给 LLM 参考"升级为"LLM 必须覆盖的要点清单"，prompt 末尾附 checklist，漏答视为不合格。
- A/B：带 RAG（公版古籍）vs 不带，比命中率。

### A5 工程保障
- 全部 A1–A3 修复**先写失败测试再修**（已知 5 个历史 bug 各留回归用例）。
- 版本锁死 + golden 全量进 CI；任何依赖升级必须 golden 全绿才并入。
- 准度看板：每法一行（对照一致率/边界用例通过率/杜撰率），随版本追踪。
