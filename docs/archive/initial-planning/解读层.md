# 解读层 · 说明

把排盘（算法层）讲成人话的一层：盘面 → 护栏 → LLM → 护栏 → 解读。LLM 可插拔。

## 用法
```python
from divination import Birth, compute
from divination.interpret import interpret, AnthropicClient

b = Birth(1990,5,15,8,30, gender="male", lat=31.23, lng=121.47, tz="Asia/Shanghai")
charts = [compute("bazi", b), compute("western", b), compute("ziwei", b)]  # 中西合参

# 测试（无需联网/Key）：
out = interpret(charts, question="今年事业如何？")        # 默认 MockClient
print(out["reading"])

# 生产（接真实模型）：
out = interpret(charts, question="今年事业如何？",
                client=AnthropicClient(api_key="sk-..."))  # 或自写 OpenAI/本地 Llama 适配器
```

## 三个组成
1. **prompts.py（核心 IP）**：
   - 系统提示=读法规范：传统文化视角、给倾向与建议而非断言、禁绝对化、
     多法分歧并陈不强求统一、不替代专业意见。
   - 各法盘面序列化：把 12 种 `ChartResult.raw/断` 翻译成 LLM 可读文字。
   - 中西合参：多法时自动提示"印证与分歧都要说明"。
2. **guardrails.py（护栏）**：
   - 输入：危机话题（自杀等）直接转介支援、不算命；医疗/法律/财务附专业转介。
   - 输出：绝对化用语（注定/必然/绝对…）自动软化为（倾向/较可能/通常…）。
   - 始终附免责声明。
3. **client.py（可插拔）**：`LLMClient` 抽象；`MockClient`（测试）；`AnthropicClient`（示例适配器，自备 Key）。

## 已验证
- 多法盘面正确序列化为合参 prompt；
- 绝对化软化、危机/医疗转介、免责注入均按规则触发（MockClient 跑通全链路）。
