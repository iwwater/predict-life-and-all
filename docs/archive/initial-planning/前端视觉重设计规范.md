# 前端视觉重设计规范（去 AI 味版）

> 替换《前端设计计划书》§7 视觉系统；其余章节（API 契约/盘面规格/合规）不变。
> 交本地 Agent 执行。**先读"反面清单"——AI 味就是这些东西堆出来的。**

---

## 0. 诊断：什么是"AI 味"

现在的问题不是丑，是**像模板**：深紫渐变背景、毛玻璃卡片、彩色渐变大标题、emoji 当图标、圆角卡片网格无限重复、千篇一律的 Inter 字体、悬浮发光按钮。这套是所有 AI 生成站的默认长相，用户一眼识破→不信任→对一个讲"准度"的产品是致命的。

## 1. 【硬约束】反面清单——以下一律禁止

- ❌ 紫色/蓝紫渐变背景、彩虹渐变文字、glow 发光效果
- ❌ 毛玻璃(backdrop-blur)卡片、半透明白边卡片
- ❌ emoji 当功能图标（🔮✨🌙 全部禁止）
- ❌ 大圆角(>8px)+大阴影的"果冻卡片"
- ❌ 首页 hero 大标语+三列功能卡的落地页模板结构
- ❌ 默认 Inter/Roboto 一种字体走天下
- ❌ "开启你的神秘之旅"式 AI 营销文案腔
- ❌ 骨架屏闪光动画(shimmer)、悬浮上浮动效满天飞

## 2. 设计语言：「古籍 × 仪器」

意象来源：**线装古籍的纸墨 + 罗盘/星盘这类精密仪器的刻度感**。气质=一位严谨的老先生，不是一个 App 创业 demo。准度是产品卖点，视觉必须传达"精确、可考、有出处"。

### 2.1 色彩（纸墨为底，朱砂点睛）
```css
--paper:    #F4EFE6;  /* 宣纸底（亮色为主！夜空黑反而是 AI 味重灾区） */
--paper-2:  #EDE6D8;  /* 卡面/分区 */
--ink:      #2B2620;  /* 墨色文字 */
--ink-soft: #6B6256;  /* 次级文字 */
--cinnabar: #B03A2E;  /* 朱砂：印章/吉/强调，全站唯一高饱和色 */
--indigo:   #2F4858;  /* 黛青：链接/西方法系标识 */
--verdigris:#5A7058;  /* 铜绿：东方法系标识 */
--rule:     #C9BFA9;  /* 界格线（古籍栏线） */
--dark-bg:  #1C1915;  /* 暗色主题=墨纸，非纯黑非夜空蓝 */
```
- 配色总量克制：一页同时出现的彩色不超过 2 种。
- 吉凶表达：吉=朱砂小印形标记，凶=墨色"※"+下划虚线，**不用红绿块**。

### 2.2 字体（最大的去 AI 味杠杆）
- 标题/卦名/术语：**思源宋体(Noto Serif SC) Heavy** 或霞鹜文楷——必须是衬线/楷感。
- 正文：思源宋体 Regular（正文也用宋体！整站宋体是"古籍感"的根，黑体正文会立刻退回 App 感）。
- 数字/度数/刻度：等宽（JetBrains Mono / IBM Plex Mono）——仪器刻度感，度数表格全用它。
- 关键术语可用直排（writing-mode: vertical-rl）做侧栏题签，如结果页右侧"庚午年命书"竖条。

### 2.3 版式（古籍栏线，不是卡片网格）
- 用**细界格线(--rule, 1px)分区**替代卡片阴影——像古籍的栏线/书口，内容区有"版心"。
- 页面有明确**版框**：内容区四周细线框 + 大留白，非全屏铺满。
- 标题不居中渐变，而是**左侧朱砂小方印 + 宋体标题 + 下划单线**。
- 信息密度可以高（专业工具不怕密），但用栏线和字号层级管理，不靠卡片切碎。

### 2.4 图形与盘面
- 盘面（星盘/九宫/卦象）是**主角**，占版面 60%+；线条 0.75–1px 细线、刻度精确，像仪器制图不像插画。
- 图标：**线性单色**（lucide 细线即可），或自绘篆刻风小图——禁 emoji、禁彩色立体图标。
- 装饰仅两类：① 朱砂印章元素（如结果页角落一枚"既济"小印）② 罗盘刻度环纹理（极淡，<5% 透明度）。再多即删。
- 正逆/动爻等状态：用传统符号（○ × 之类爻变标记），不用现代 badge 胶囊。

### 2.5 动效（克制到近乎没有）
- 全站动效只允许三处：翻牌（塔罗）、摇卦（铜钱）、罗盘指针归位。各 ≤600ms，缓动 ease-out。
- 页面切换无转场，内容直接落位。加载态用"墨点呼吸"单点动画，不用骨架屏闪光。
- 解读流式输出像**毛笔逐行书写**的节奏感（按句出现，不逐字符蹦字）。

### 2.6 文案腔调
- 术语用本名：八字命式/排盘/起卦/坐向——不写"AI 智能分析你的命运"。
- 按钮动词化且短：「排盘」「起卦」「观盘」「化解之法」。
- 免责声明排成古籍"凡例"样式（小字宋体+界格框），庄重而非律师函式灰小字。
- 每个结论旁可点开**出处小注**（"《滴天髓》论旺衰"）——准度的视觉化：让"有依据"看得见。

## 3. 关键页面落地示意

- **首页**：不是 hero 落地页。一开门就是**排盘台**——左竖排题签"命 卜 相 山 医"五术导航，中间出生信息录入（界格表单），右侧一方罗盘刻度装饰。一屏即用。
- **结果页**：版框内左 65% 盘面制图，右 35% "批文"栏（宋体竖题签+解读正文+出处小注），底部"化解之法"独立一栏（free 方案排前，朱砂小印标"宜"）。
- **平面图页**：标注画布像**工程图纸**（米白底+细线+等宽标注字），不像绘图玩具。

## 4. 实施说明（给 Agent）

1. 本规范**整体替换**原计划书 §7；§5 各盘面规格的元素要求不变，按本语言重绘样式。
2. 先做一页**风格样张**（结果页静态稿）交付确认，再铺全站——防止理解偏差后返工。
3. 反面清单为验收项：终验时逐条扫描，命中任何一条打回。
4. 字体加载：中文宋体字体子集化（subset）控制体积；数字等宽全站统一。
5. 暗色主题用 --dark-bg 墨纸方案，亮色为默认主题（与现行业暗色 AI 站反着走，本身就是辨识度）。
