# 中国玄学各法 · 文献依据与验证

本引擎中国玄学部分的排盘规则均依传统文献，关键定数已实测对标。

## 八字 / 四柱（子平术）
- 文献：《渊海子平》《滴天髓》《三命通会》《穷通宝鉴》
- 实现：lunar-python（节气换月、十神、大运、胎元/命宫/身宫、纳音）
- 已处理：真太阳时校正（经度差+均时差，误差<0.1分钟）、历史夏令时（1986–91 中国夏令时自动正确）

## 紫微斗数
- 文献：《紫微斗数全书》（陈希夷传、罗洪先编）
- 实现：py-iztro（十二宫、主星、四化、命主身主、五行局）

## 奇门遁甲（时家）
- 文献：排盘心法《烟波钓叟歌》（托名风后）；另参《奇门遁甲统宗》《奇门遁甲秘笈大全》
- 实现：kinqimen
- **已验证**：阴阳遁与三元局数（上/中/下元）对《烟波钓叟歌》二十四节气三元定局表，
  7 个节气（含阴遁阳遁）**全部一致**。九星/八门/八神已还原为文献全称。

## 六爻（纳甲筮法）
- 文献：《京氏易传》（西汉·京房）纳甲与八宫；断法《增删卜易》《卜筮正宗》
- 实现：自写。三钱起卦（6老阴/7少阳/8少阴/9老阳），本卦/变卦/动爻，
  京房纳甲装地支+六亲，八宫定世应，日干起六神。
- **已验证**：64 卦文王卦序表（10 个已知卦校验全对）；乾为天纳甲六亲与文献一致；
  八宫世应索引全 64 卦完整，乾宫八卦世位逐卦校验通过。

## 梅花易数
- 文献：《梅花易数》（北宋·邵雍）
- 实现：自写时间起卦法（先天八卦数），主卦/互卦/变卦、体用、动爻。

## 称骨算命
- 文献：袁天罡《称骨歌》（唐）
- 实现：自写。年(60甲子)/月/日/时四柱骨重表（传统公版定数）相加，查《称骨歌》批语。
- 注：骨重计算为确定性可核；批语为歌诀首句，完整四句建议据印本《称骨歌》校订。

# 断法层（排盘→断吉凶）· 文献与实现

各法在排盘基础上新增「断」字段，规则依传统文献：

## 八字 · 旺衰多因子（W1 升级）
- **藏干计权**：地支藏干表（本气1.0/中气0.6/余气0.3，通行计权，流派或异），五行力量=天干+藏干加权，再乘月令旺相休囚死系数（旺1.0/相0.8/休0.5/囚0.4/死0.3）。
- **日主旺衰三因子**：得令（月令旺相）+ 得地（通根：四支藏干寻根，月支×2.0/日支×1.2/年时×0.8）+ 得势（同党[比劫+印] vs 异党加权分），合成六级（从弱~身强）。
- **扶抑取用（粗）**：弱喜印比、强喜食伤财官、中和待调候。调候（《穷通宝鉴》）与格局例外未含，留断语层。
- **子时开关**：`zi_hour='late'(默认,23点不换日)|'early'`，显式可选。
- 验证：庚生巳月（巳藏庚=得地）判中和；三寅甲木判身强；子月众水丙火判从弱。

## 奇门 · 格局（《奇门遁甲统宗》《烟波钓叟歌》）
- 已实现（五行可推、确定）：**门迫/门制**（门宫五行生克）、**入墓**（天盘干入墓库宫，已校乙→坤未、丁→乾戌）、
  **空亡宫**（时空落宫）、**五不遇时**（时干克日干）、**值使临吉/凶门**。
- 暂未实现：青龙返首、飞鸟跌穴、白虎猖狂等**干组合格局**——其确切天/地盘干组合须据《奇门统宗》格局表逐条校订，
  为免出错此处留空，不臆造。

## 六爻 · 用神断（《增删卜易》《卜筮正宗》）
- 按问事类别取**用神六亲**（求财→妻财、事业→官鬼、文书房产→父母、平安子女→子孙、合伙竞争→兄弟）。
- 标注**旬空**（日旬空）、**月破**（月支冲）、**日冲**；用神**旺衰**依月建+日辰生克。
- 用神不上卦时如实提示需取伏神。

## 梅花 · 体用生克（《梅花易数》断卦总诀）
- **体用关系**定吉凶：用生体/比和=吉，用克体=凶，体生用=耗泄，体克用=吉可控。
- 互卦看过程、变卦看结果。

## 称骨 · 批语
- 即《称骨歌》批语本身（批语首句，完整四句建议据印本校订）。

# 风水堪舆（可计算部分）

峦头形势（觅龙、察砂、观水、点穴）属定性相地，不算法化；可计算的理气派如下。

## 玄空飞星（理气）
- 文献：《沈氏玄空学》(沈竹礽)、《飞星赋》《玄空秘旨》、蒋大鸿《地理辨正》。
- 实现：三元九运定运 + 二十四山阴阳顺逆飞泊，排运盘/山盘/向盘九宫，
  判旺山旺向/上山下水/双星到向(坐)。
- **已验证**：八运子山午向=双星到向（向首双8）、午山子向=双星到坐、
  丑山未/未山丑向=旺山旺向，皆合《沈氏玄空学》；当前下元九运(2024–2043)正确。
- 简化处：5 入中时借坐山卦定顺逆（学派有别，可再细化）。

## 八宅（理气）
- 文献：《八宅明镜》(箬冠道人)。
- 实现：三元命卦 → 东四命/西四命 → 八游年（生气/天医/延年/伏位为吉，
  绝命/五鬼/六煞/祸害为凶）排八方。
- **已验证**：1990 男=坎命(东四,吉方坎离震巽)、女=艮命(西四)。
- **待校订**：命卦严格应以**立春**为年界（非公历元旦）；且 **2000 年后**男命公式有
  「11−s」与「9−s」两派，临界年需按所宗流派校定。

# 西方·其余术数（补齐）

## 吠陀占星（Jyotish）（已深化）
- 标准：Lahiri ayanamsa、十二宫(Rashi)、二十七宿(Nakshatra)+Pada、九分盘(Navamsa/D9)、庙旺落陷(dignities)、Vimshottari 大运(120年九曜)。
- 实现：skyfield 回归黄经 − Lahiri 岁差 = 恒星黄经；九曜含**罗睺/计都**(平月交点公式)；
  Navamsa 用整数式 (lon×3)//10；Vimshottari 由月亮所在宿定起运主星+余额，排大运(Mahadasha)+副周期(Antardasha)。
- **已验证**：摩羯入境合 Makar Sankranti；Dasha 九曜总和=120年；Navamsa 合古典元素规则(动/固/变宫起例)；罗睺逆行≈19.38°/年。

## 塔罗（已深化）
- 体系：韦特(Rider-Waite-Smith，已入公有领域)。78 张牌（大阿卡纳22+小阿卡纳56）。
- 实现：78 张**全部含正/逆位牌义**（小牌逐张，不再只给花色主题）；大阿卡纳含**占星对应**（供中西合参，如 恋人-双子、塔-火星）；
  **9 种牌阵**，每阵含位置定义+**解读要领**（位置间关系读法，注入 LLM）+适用问题：单张/时间之流/现状-行动-结果/二择一/关系之镜(6张)/马蹄铁(7张)/身心灵/年运十二宫(12张)/凯尔特十字(10张)；
  **牌组整体分析**：大牌占比、逆位比例、花色集中、宫廷牌数 → 整体提示。
- 牌义为传统关键词联想，自有措辞，不引用任何特定著作文本。
