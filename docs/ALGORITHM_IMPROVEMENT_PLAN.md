## 3. 通用改进项

### 3.1 引擎接口统一
所有 `compute(b: Birth, **kw)` 应返回更结构化的 `ChartResult`，含：
- `confidence`: 0-1 置信度
- `evidence_sources`: 列出依据的规则 ID（如 `yhz_001`）
- `classical_texts`: 关联的古籍（用于文献出处）
- `reasoning`: 推理链

### 3.2 错误处理增强
每个引擎应有：
- `validate_input(b: Birth)` 验证
- 边界条件处理（如闰月、跨日、真太阳时）
- 友好的错误信息（不只 stack trace）

### 3.3 多语言支持
输出除中文外应支持英文（已有 i18n 框架）

### 3.4 性能优化
- 大数据计算缓存
- 避免重复计算（如合盘）
- 异步 I/O 准备（AI 解读集成）
