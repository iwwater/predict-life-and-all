- 名用字表：**80 个常见名用字**
- 数理吉凶：**1-81 完整**（大吉 21 / 半吉 14 / 凶 25）

### 五格计算
- **天格** = 姓总笔画 + 1（复姓 = 姓总笔画）
- **人格** = 姓末字笔画 + 名首字笔画
- **地格** = 名总笔画 + 1（单字名）或 = 名总笔画（双字名）
- **外格** = |总格 - 人格 + 1|（按单/双字名不同公式）
- **总格** = 姓 + 名 所有笔画之和

### 三才关系链
- **天人 + 人地** 五行关系（生/被生/克/被克/比和）
- 综合判断：大吉/吉/半吉/凶（基于三格数理均值）
